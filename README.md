# AtomCorp Lite

Небольшая интерактивная демка **AI-native CRM**: поручение → команда специализированных агентов → факты → предложения → подтверждённые действия.

Демонстрационные роли работают с одним состоянием CRM:

| Роль | Задача | Результат |
|---|---|---|
| Координатор | Разобрать поручение и собрать результаты | Общий ответ и предложения задач |
| Гигиенист | Сопоставить карточки по телефону | Возможные дубли с объяснением |
| Аналитик | Посчитать показатели по карточкам | Воронка, суммы, открытые задачи |

Это компактный пример для изучения и развития идеи. Все контакты, компании, телефоны, суммы и события вымышлены. **Языковая модель и Bitrix24 не подключены**: выбор сценария и ответы детерминированы. Никаких платных сервисов, ключей и фоновых сетевых запросов.

## Открыть

Скачайте репозиторий через **Code → Download ZIP**, распакуйте и откройте `index.html` в современном браузере. Сборка и установка зависимостей не нужны.

Либо запустите локальную раздачу:

```sh
python3 -m http.server 8080
```

Откройте <http://localhost:8080>. При наличии Node.js можно использовать `npm start`; команда также требует Python 3.

## Попробовать за две минуты

1. Откройте **Команду агентов** и отправьте «Проверь базу».
2. Посмотрите результат: одна пара дублей и два обращения без внимания.
3. Нажмите **Проверить** рядом с дублем. Прочитайте основание и подтвердите объединение. Заметки сохраняются, вторая карточка доступна в разделе **Объединённые**.
4. Создайте задачу из предложения координатора, затем завершите её в разделе **Задачи**.
5. Отправьте «Покажи сводку»: ответ строится по текущему состоянию, включая ваши изменения.
6. Кнопка **Начать заново** восстанавливает исходный пример.

Также доступны «Найди дубли» и «Кому нужна задача?». Другие запросы показывают список поддерживаемых примеров. Изменения по возможности сохраняются в локальном хранилище браузера; если оно недоступно, приложение работает до закрытия страницы и показывает уведомление.

## Устройство

```text
index.html          оболочка и окно подтверждения
src/data.js         исходные вымышленные карточки
src/core.js         поиск дублей, объединение, задачи, журнал
src/app.js          координация сценариев, ответы, экраны, сохранение
src/app.css         адаптивное оформление
tests/core.test.cjs проверки операций с данными
```

Поиск дублей нормализует телефон, включая российские префиксы `8` и `+7`. Совпадение телефона — только сигнал для проверки: в реальной CRM один контакт может иметь несколько самостоятельных заказов. Поэтому объединение требует отдельного подтверждения. Сумма оставшейся карточки не складывается с суммой дубля, обе записи и их заметки сохраняются.

Предложение задачи не создаёт её автоматически. Журнал фиксирует проверки и подтверждённые изменения. «Лид без внимания» означает отсутствие касания минимум пять дней, а не отсутствие задачи: создание задачи само по себе не обнуляет этот показатель.

## Развить идею

1. Заменить обработчик `reply()` в `src/app.js` серверным координатором с языковой моделью. Ключи моделей держать на сервере.
2. Дать специалистам отдельные инструменты чтения CRM с чёткими входами и результатами. Считать суммы и показатели инструментами, а не поручать модели придумывать их.
3. Подключить Bitrix24 через серверный адаптер вместо `createDemo()`. Привязать действия к пользователю и его правам.
4. Сохранить цепочку **предложение → просмотр последствий → подтверждение → применение**, а также повторную проверку актуальности карточки перед записью.
5. Добавить серверный журнал, защиту от повторных действий, отмену, очередь выполнения, обработку ошибок и контроль доступа.

Здесь нет серверной авторизации, совместной работы, настоящей автономной оркестрации или готового подключения к рабочей CRM. Локальное хранилище не предназначено для рабочих данных. Это намеренно маленький пример архитектурной идеи.

## Проверки

Нужен Node.js 18+; сторонних пакетов нет.

```sh
npm test
```

Проверяются нормализация телефонов, сохранение заметок при объединении, отказ от повторного/необоснованного объединения, повторное завершение задачи и экранирование текста.
